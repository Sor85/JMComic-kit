下载配置

填写要下载的本子ID，支持批量下载。

选择之前导出的收藏夹CSV文件，导入后会自动填充到下方的本子ID输入框
用 / 分隔目录层级。常用字段: Aauthoroname([作者]标题), Atitle(标题), Aid(本子ID), Pindextitle(第X話 标题), Pindex(章节)
支持 mb/kb 单位，如 10mb、512kb

自动化同步

定时同步收藏夹，自动下载新本子到本地，跳过已有本子。

新建自动化任务

示例：0 */6 * * * (每6小时) | 0 2 * * * (每天凌晨2点) | 0 0 * * 0 (每周日凌晨) Cron 表达式生成器
支持 mb/kb 单位，如 10mb、512kb
用 / 分隔目录层级。常用字段: Aauthoroname([作者]标题), Pindextitle(第X話 标题), Aid(本子ID), Atitle(标题)
每批下载多少个本子，建议 30-100
每批下载完成后等待时间，建议 20-60
